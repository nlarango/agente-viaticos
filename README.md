# Agente de viáticos

Asistente que responde preguntas sobre la política de viáticos usando los documentos de `conocimientos/`.

## Ejecución

```bash
cd /Users/franz/Documents/Personal/Nata/cursoapp/agente-viaticos
.venv/bin/python agente.py "¿Cuánto puedo gastar en hospedaje en medellin?"
```

Requiere un archivo `.env` con `GEMINI_API_KEY=tu_clave`.
